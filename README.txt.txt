# 🚚 Dynamic Transport Logistics and Route Optimization System

## 📌 Overview

This project is a **Python-based logistics management system** that helps in managing transport routes and optimizing them based on minimum distance. It also includes vehicle management using object-oriented programming concepts.

## 🎯 Features

* Add and manage trucks with capacity and fuel efficiency
* Add multiple transport routes
* Find the **shortest (optimized) route**
* Visualize route distances using graphs
* Input validation for better user experience

## 📊 Sample Functionality

* Enter truck details (ID, capacity, fuel efficiency)
* Add routes with source, destination, and distance
* System finds the **best route (minimum distance)**
* Displays a **bar chart visualization** of all routes

---

## 🧠 Concepts Used

* Object-Oriented Programming (OOP)
* Inheritance (Vehicle → Truck)
* Data Handling with Pandas
* Numerical computation with NumPy
* Data Visualization using Matplotlib
